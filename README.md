## 🔧 What I build

### 🤖 AI-powered anomaly distribution (Kiro / Agent Space)
Built an automated engine that segments daily attendance anomalies **by responsible manager** and auto-distributes personalised, ready-to-act summaries — replacing a single bulk report that managers had to self-filter. Deployed across MENA and Morocco. Cut time-to-action on anomaly clearance and sustained pre-payroll punch compliance.
`Python` · `Outlook COM automation` · `AI agents` · `cross-functional workflow design`

### 🧮 Payroll validation macros (Turkey)
Two automation tools that are now the monthly quality gate for Turkey payroll:
- **Union List Validation Macro** — cross-references each month's union roster against the prior month to auto-flag anomalies feeding bonus calculations.
- **PES vs Pay Summary Validation Macro** — reconciles payroll-engine output against the source dashboard as an automated payfile integrity check.

Combined June result: **zero** union errors, **zero** PES variances, **zero** unjustified absences across 1,562 employees.
`Excel/VBA` · `data reconciliation` · `payroll data quality`

### 📉 Data-driven defect-reduction campaigns
Ran sustained monthly RCA + mitigation programs. South Africa pay defects: **29 → 10 (64% reduction)** across six months, with formal trend reporting to leadership.
`Root cause analysis (DMAIC)` · `stakeholder reporting` · `trend analytics`
